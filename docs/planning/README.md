# Feature planning and acceptance

The [roadmap](roadmap.md) owns priorities, points and delivery gates. The [acceptance ledger](completion-sprints.md) owns story statuses, and [feature-acceptance.json](feature-acceptance.json) fixes the baseline. Run `npm run status:features` from the repository root to calculate the verified-story percentage. Partial implementations do not receive verified credit.

The [Rust plan](rust/README.md) is a separate migration scope; its points are not added to feature-backlog points.
