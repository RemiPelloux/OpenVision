# OpenVision 0.2.0-preview.3 — Your project workspace

Download **OpenVision-0.2.0-preview.3-win32-x64.zip**, extract it, and double-click
**OpenVision.cmd**. The complete Windows x64 app is included; no separate editor,
Node.js or npm installation is needed to launch it. The repository also includes
seven verified payload parts for offline installation with **Run-OpenVision.cmd**.

- Start in Project Home: animated eye, searchable recent projects, pinned favorites,
  open-window focus, saved workspaces and bounded history pages.
- Use native Ctrl+K Quick Edit with your selected custom provider/model, review,
  undo and cancellation.
- Receive clearer DNS/connection/TLS guidance, with explicit manual retry.
- Keep memory reviews synchronized across windows and import into the active
  default profile. Recover import backups after restart using the documented CLI.
- Expanded native JavaScript/C checks cover cross-file rename, navigation,
  Save All, undo/redo and overlapping edits to separate files.
- REA now has 14/15 complete WebAssembly inspection records; the remaining
  large build helper exceeds the current bounded inspection contract.
