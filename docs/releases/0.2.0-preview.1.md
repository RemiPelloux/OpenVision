# OpenVision 0.2.0-preview.1

**Public development preview · 14 October 2026 · customization source only**

OpenVision brings a local profile, custom AI connections, project development
and original visual identity to an editable desktop workspace. This first tagged
preview packages the customization code, verification tools and documentation.
GitHub's source archives contain those tracked files, not a runnable editor.

## Included

- Custom provider URLs and keys, model discovery/manual IDs, grouped searchable
  selectors and per-model reasoning choices.
- Local project rules and approved memories, reviewed legacy-memory imports,
  large-paste references and `.openvision/` project paths.
- Custom-provider Tab autocomplete with Unicode/multiline insertion, partial-word
  acceptance, safe undo and pending-request cancellation.
- Windows development workflows covering project files, JS/TS, optional C/C++,
  Save All, Git/worktrees, terminals, tasks and Node debugging.
- Built-in telemetry disabling, local chat titles and scoped resource/lifecycle
  improvements. Performance claims remain tied to measured workloads.

## Important fixes

The latest runtime change, `f0c0bc1`, fixes Escape leaving a pending autocomplete
request running and partial acceptance merging with the user's preceding space
in undo history. Two native Windows runs passed exact undo and upstream request
cancellation. Earlier changes reject incomplete completion responses, retain
saved model catalogs and fix concurrent rule persistence and shutdown ordering.

## Prepare and run

Install Node.js 24.18.0, npm and Git. Provide compatible native inputs as described
in the [runtime guide](../guides/native-runtime.md), then run from the repository root:

```sh
npm ci --prefix tooling
npm run prepare:desktop
npm start
```

For an existing prepared checkout, update the source and dependencies, run
`npm run build:desktop`, then fully restart OpenVision. Preserve `data/` and
backups. The preview does not contain API credentials, generated runtime bundles
or an installer. No GitHub Actions are required or enabled.

## Evidence and known limitations

- **6/42 stories Verified (14.29%)**; 21 Partial, 13 Planned, 2 Unknown. This is
  acceptance coverage, not an implementation or decompilation percentage.
- Windows x64 native editing checks pass with controlled HTTP fixtures. Separate
  small live Codex Easy probes passed for GPT, DeepSeek and Grok; they do not
  establish broad model quality or every reasoning tier.
- The latest autocomplete changes passed focused tests, desktop syntax/build
  validation and two native editing/cancellation runs with clean host exits.
- An earlier development-host exit 134 remains unexplained. Retrieval/indexing
  ownership, next-edit prediction, full remote development, independent builds,
  installers/updates and macOS/Linux runtime acceptance are unfinished.
- Public access is not a project-wide license or permission to redistribute
  locally supplied third-party artifacts. See [licensing scope](../../NOTICE.md).

The [feature roadmap](../planning/roadmap.md) lists all 36 unfinished stories,
dependencies and complexity points. The [verification matrix](../verification/release-claims.md)
defines the exact scope of each claim.

The later [Rust rewrite track](../planning/rust/rust-roadmap.md) is future architecture work;
this release contains no Rust runtime replacement.
