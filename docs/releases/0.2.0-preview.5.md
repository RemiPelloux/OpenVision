# OpenVision 0.2.0-preview.5 — native themes

Project Home and Clone Repository now use a simple editor-style layout and the
selected theme. The fixed green palette, oversized headings, tinted cards and
blurred clone backdrop have been removed. The small monochrome eye remains.

- **Color theme** on Project Home opens the native theme picker.
- **Local Profile → Appearance settings** opens the editor's color settings.
- Home, cloning, profile buttons and custom-model controls use native theme colors.
- Custom colors, typography and icon themes are covered in the
  [appearance guide](../appearance.md).
- Home uses the editor’s native theme service, resolving a separate saved
  preference that could restore dark after selecting light or override custom colors.

Download **OpenVision-0.2.0-preview.5-win32-x64.zip**, extract into a fresh
directory and run **OpenVision.cmd**. The repository includes the complete
payload for **Run-OpenVision.cmd**. Preserve the old profile when updating;
see [installation and updates](../native-runtime.md).

This remains a Windows x64 development preview. Native macOS/Linux, signing,
full upgrade/rollback and independent native rebuilding remain open. The
fixed acceptance count stays **6/42 Verified**. GitHub Actions remains disabled.
