# OpenVision 0.2.0-preview.6 — projects in one window

Opening a project now uses your current window, including recent projects,
native folder/workspace pickers and completed clones. A project already open
elsewhere focuses its existing window. Canceling the native unsaved-file prompt
keeps your project and unsaved text intact.

The simple theme-aware layout remains: select **Color theme** on Home or
**Local Profile → Appearance settings** for colors, fonts and icons.

## Download and update

Download **OpenVision-0.2.0-preview.6-win32-x64.zip**, extract into a new folder,
and run **OpenVision.cmd**. No Node.js, npm or separate editor is needed.
The full payload is also included in Git for **Run-OpenVision.cmd**.

For an existing installation, close OpenVision, back up the old
`electron-host/data/` directory, then copy it into the new package before launch.
Keep the old app for rollback. The repository installer deliberately refuses to
overwrite another version: use a fresh destination as described in
[installation and updates](../native-runtime.md). Keys may need re-entry on a
different machine; no author profile or keys are distributed.
