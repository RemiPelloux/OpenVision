# OpenVision 0.2.0-preview.4 — repository cloning

Clone Repository now opens a clear URL form instead of the generic source picker.
Paste your repository URL, choose a destination and OpenVision opens the completed
checkout in a new editor. Existing checkouts are preserved.

## Changes

- Accessible clone dialog with inline validation, keyboard focus, Escape/Cancel
  and a compact layout. Failed or canceled clones open no project.
- MCP cleanup reports a pending close after five seconds while retaining its
  actual resource ownership. Repeated requests share one close operation; a
  diagnostic logger failure cannot strand cleanup bookkeeping.
- Quick Edit sends exact duplicate code attachments once. Distinct paths, ranges,
  contents and metadata remain intact. This reduces duplicated request bytes;
  whole-app RAM and billed-token reductions have not been measured.
- Native provider verification now exercises self-signed TLS certificate rejection
  and explicit retry without changing trust settings.

## Run

Download **OpenVision-0.2.0-preview.4-win32-x64.zip**, extract it and double-click
**OpenVision.cmd**. The repository also includes the complete payload and
**Run-OpenVision.cmd**. No Node.js or separate editor installation is needed for
normal use. Git must be installed for cloning and source control.

When updating, extract into a fresh directory. Preserve your existing
`electron-host/data` profile before moving to the new package. The repository
installer refuses to overwrite a different version; the [installation guide](../native-runtime.md)
explains profile locations and manual updates.

## Evidence and limits

Native Windows checks cloned a real public HTTPS GitHub repository and local Git
fixtures, checked HEAD/origin/files, and exercised cancellation, duplicate
destinations, failure recovery and keyboard/compact UI behavior. Private Git
authentication and SSH transport remain unverified. See [Project Home](../project-home.md)
and [portable verification](../portable-preview4.md).

MCP native fault-injection tests use real local transports; Quick Edit and provider
error tests use controlled local servers. Those checks are not live AI-provider
quality tests. macOS/Linux, signing, full upgrade/rollback and independent native
rebuild gates remain open. The fixed acceptance count stays **6/42 Verified**.
GitHub Actions remains disabled.
