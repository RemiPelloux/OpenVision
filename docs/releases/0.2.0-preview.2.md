# OpenVision 0.2.0-preview.2 — Portable desktop

**The complete Windows x64 app is included.** Download
**OpenVision-0.2.0-preview.2-win32-x64.zip**, extract it, and double-click
**OpenVision.cmd**. No separate editor, Node.js or npm installation is required.

The complete payload is also tracked in Git as seven numbered parts. Clone or
download the repository, then double-click **Run-OpenVision.cmd**. The offline
installer verifies each part and the full archive before extracting.

## Included

- OpenVision desktop executable, editable application JavaScript, extensions and native modules.
- Animated eye welcome screen, local profile, project explorer, editing, terminals and Git workflows.
- Custom AI URLs and keys, model discovery, grouped model selection, reasoning choices and Tab autocomplete.
- Local `.openvision/` project configuration and reviewed memories.
- Third-party license notices. No author profile, keys, chats, backups or logs.

## Verification and remaining work

Relocated native autocomplete/edit/save/undo and typing/Escape/file-switch
cancellation passed with a disposable profile and controlled HTTP provider.
The repository installer reconstructed and extracted the full app; the extracted
build passed animated welcome, reduced motion, local workspace entry and clean
shutdown checks. The extracted Agent passed streaming, file Read, two-file
Keep/Reject, command approval/denial/Stop, upstream cancellation and restart/resume
against the controlled provider. See [portable verification](../portable-verification.md).

This is a development prerelease. **6/42 complete acceptance stories are verified**;
packaging does not grant credit for unfinished story clauses. Native ARM64,
macOS/Linux, full upgrade/rollback coverage, independent native-source rebuilding
and broader live-provider workflows remain open. The package is not signed with
an OpenVision publisher certificate.
