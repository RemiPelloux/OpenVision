# OpenVision 0.2.0-preview.7 - local AI workflows

This preview brings the recent Agent recovery, provider settings, account
integrations and resource-lifetime fixes into a new Windows x64 portable app.
Download **OpenVision-0.2.0-preview.7-win32-x64.zip**, extract it into a new
folder and double-click **OpenVision.cmd**. Node.js, npm and a separate editor
installation are not required. The repository includes the same payload for
**Run-OpenVision.cmd**.

## Features available

- **Projects and editing:** theme-aware Project Home, recent projects, favorites,
  Git cloning and same-window opening; Explorer, search, terminals, tasks,
  JavaScript/TypeScript tools and Git/worktrees. C/C++ tooling is an optional setup.
- **Your AI connections:** custom URLs, API keys, model names and discovery;
  grouped/searchable models and model-specific reasoning choices. Additional
  authentication headers are masked and kept in secret storage.
- **Agent and Quick Edit:** file reads, proposed edits, review/accept/reject,
  Undo/Redo, explicit retries and cancellation. Snapshot failures retain retryable
  state; header/body inactivity limits survive proxy selection.
- **Tab completion:** select an independent API model, accept suggestions with
  Tab, undo and cancel stale requests. Next-edit prediction remains planned.
- **Optional accounts:** ChatGPT/Codex and Claude/Claude Code setup, isolated
  profiles, account switching, deletion that preserves history and reported
  usage in the bottom bar. Account models appear in Agent when eligible.
- **Local customization:** local profile, `.openvision/` rules/plans/skills,
  approved memories, settings import, local chat titles and large-paste files.
  MCP supports configured HTTP/STDIO tools with scoped cancellation/recovery.

## Improvements in this package

Custom headers now follow the chosen provider through discovery, Agent,
subagents, Tab completion and Quick Edit. Explicit `Authorization` takes
precedence over default Bearer authentication, including Agent capability
discovery. Missing credentials fail explicitly; failed secret deletion remains
owned and retryable. [Header behavior and limits](../engineering/provider-authentication-headers.md).

Recent fixes preserve failed edit-review history, correct pending/in-flight
settings writes, defer Explorer initialization and release completed utility
listeners. Account routing reuses unchanged state and streamed output avoids
duplicate retention. Chat titles use the first message locally, avoiding a
separate AI title request. These are scoped improvements; no universal speed
or whole-app RAM reduction is claimed.

## Limits and update instructions

This is an **unsigned Windows x64 development preview**. Account integration
is experimental: Codex offers only eligible GPT-6 models returned by its client;
Claude usage may be unavailable. Accounts support text/tools, while Tab
completion uses API connections. First-time account setup downloads its official
integration and requires the provider's browser sign-in.

Linux x64 has separate local source-build evidence. This release does not add
a Linux or macOS binary. Retrieval/indexing ownership, next-edit prediction,
remote-development coverage, independent native rebuilding and full
upgrade/rollback acceptance remain open.

Close the old app, back up `electron-host/data/`, extract into a **new folder**,
then copy your data before launching. Keep the old installation for rollback;
keys may need re-entry on another machine. The repository installer protects
existing installations and requires a fresh destination for a different version.
See [installation and updates](../guides/native-runtime.md).

The [roadmap](../planning/roadmap.md) and [Rust plan](../planning/rust/rust-roadmap.md)
