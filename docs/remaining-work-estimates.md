# OpenVision roadmap

The current [feature roadmap](roadmap.md) uses complexity points and acceptance
gates. It covers all 36 unfinished stories and links to the [Rust rewrite](rust-roadmap.md).

For preview.6, the [next priorities](roadmap.md#preview6-delivery-and-next-priorities)
cover conversation recovery (8 points), shutdown reliability (8), provider
failure cases (5), project lifecycle/scale (5), and autocomplete quality (8).
These are selected rows from the full roadmap, not additional work to add twice.

Points express relative scope and uncertainty; they are not calendar dates.
Release readiness depends on passing the named acceptance gates. The ledger
remains 6/42 fully Verified, with 28 additional stories needed for the 80% target.
