Your workspace.
Your models.

OpenVision is an AI coding workspace that runs on your machine. Connect any OpenAI-compatible API, your own server or a local model — keys stay in your OS keyring, and nothing is sent anywhere you did not configure.

Get started Download preview.7 View on GitHub

Everything you need to code with AI — on your terms

🔑

Your models, your keys

Any OpenAI-compatible API, your own server or a local model. Models are discovered; keys stay in the OS keyring.

🤖

An Agent that asks first

Multi-file edits you review and undo, tools that run only after approval, and Stop that leaves your files intact.

⚡

Tab completion

A separate completion model, accepted with Tab, undoable and cancellable. Off until you pick a model.

🧩

MCP, rules and memories

HTTP and STDIO MCP servers with OAuth, project rules and agents under .openvision/, memories you approve.

🛡️

Local by default

No sign-up. Built-in analytics and crash upload are disabled by the build, and verified by network captures.

🔎

Search, Git and remote

Local code search, Git and worktrees, terminals and debugging, Project Home and SSH remote windows.

Start in minutes

# build locally from a pinned, checksum-verified input
git clone https://github.com/RemiPelloux/OpenVision.git && cd OpenVision
npm ci --prefix tooling
npm run prepare:desktop
npm start

Keys use gnome-keyring, KWallet or KeePassXC. Linux guide →
